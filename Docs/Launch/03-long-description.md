# Long description
Discover and use browser-based alternatives to popular desktop applications. The browser tools need no desktop installation or AICraft subscription; the optional bank feed requires separately configured services and authorized access.

AICraft helps you find a focused tool for photos, PDFs, vector shapes, documents, spreadsheets, presentations, audio, video and more. Search the catalog, compare what an application can actually do, and launch it without installing a desktop package.

Each application has a dedicated page with a workflow preview, features, limitations, access information and upstream licensing links. Photo lab opens the full PhotoCraft browser editor; the lightweight photo workflow at `/photo/basic`, PDF lab and vector lab use browser workers. Ledger Reborn provides browser-local bookkeeping with reviewed imports from a separate bank feed. Tax Reborn provides an independent, experimental tax year 2025 preparation interface with no electronic filing. The full upstream editors use pinned browser releases.

These are practical alternatives for specific workflows, not promises to replace every feature of a desktop suite. CADCraft graphics startup remains unverified, mobile editor compatibility varies, and larger engines can take time to load. Save and check exports before relying on them.
