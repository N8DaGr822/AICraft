# Product Hunt submission draft
Name: AICraft
Tagline: Free creative tools, right in your browser
URL: https://n8dagr822.github.io/AICraft/

Description: Discover free browser-based tools for photos, PDFs, documents, spreadsheets and more. Compare features and limitations, then open the application. No installation or AICraft subscription required.

Maker comment: I built AICraft to make useful browser tools easier to discover. It combines focused labs with pinned upstream editors, with credit and licensing links on each application page. It is still experimental: desktop parity is not the goal, and some editors need a capable desktop browser. I'd love feedback on which workflows work well and where the limitations need clearer explanations.

Before submission: verify current platform rules and field limits; choose actual screenshots; complete the launch checklist. Do not claim popularity, ratings or open-source status for the whole platform.
