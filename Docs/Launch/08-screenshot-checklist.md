# Screenshot checklist
- [ ] Capture the deployed homepage at desktop and narrow mobile widths.
- [ ] Capture search results, category filtering and a no-results state.
- [ ] Capture an application page showing its limitation and licensing sections.
- [ ] Capture a photo before/after with a non-sensitive, rights-cleared sample.
- [ ] Capture PDF page organization and a verified downloaded result.
- [ ] Capture vector layers and an exported SVG.
- [ ] Capture representative upstream editor workflows only after successful startup.
- [ ] Use synthetic ledger records only.
- [ ] Remove personal names, local file paths and unrelated tabs from promotional images.
- [ ] Supply descriptive alt text and inspect small-screen readability.

Current landing pages use honest text workflow previews; they do not show fabricated editor screenshots. Set PreviewImage in the catalog only after a real screenshot has been reviewed and the renderer supports it.
