# Product description
AICraft is an independent directory of free browser-based creative and productivity tools. It brings together four focused browser labs and ten pinned upstream editors, with application pages describing features, licensing, data handling and limitations.

The host uses Blazor WebAssembly; discovery pages are static HTML. AICraft does not claim authorship of the upstream editors, desktop feature parity, or ownership of third-party code. Original AICraft code is MIT-licensed.
